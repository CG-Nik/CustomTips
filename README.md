# CustomTips
This mod creates a set of lines that allows players to see the borders of the chunk that they're in.  
This mod works on the client, and has no meaningful purpose on the server.  

This mod has config in your MelonPreferences.cfg (located in A Township Tale\UserData) that allows you to modify the tips that show up on the loading screen.
You can also modify whether the tips are shuffled (true = shuffled, false = unshuffled),
whether the list of tips you set overwrites the tips that the game has or adds to them (true = overwrites, false = adds to the list),
and the duration that tips show up for (default is 5.0 seconds, which is the value that the base game uses).

This is an unofficial, fan-made mod for A Township Tale. This mod is not affiliated with or endorsed by the owners or developers of A Township Tale.
